# Function Pointers

This directory contains C exercises covering function pointers, callbacks, and compilation under `gcc -Wall -Werror -Wextra -pedantic -std=gnu89` following the Betty coding style.

## Files
- `function_pointers.h`: Header file containing function prototypes and include guards.
- `0-print_name.c`: Function `print_name` that invokes a callback function pointer to print a name.
